# Raaghul — AI & Data Science Portfolio

A responsive React/Vite personal portfolio.

## Run locally

```bash
npm install
npm run dev
```

Open the URL printed by Vite (usually http://localhost:5173).

## Before publishing

1. Replace `YOUR_EMAIL@example.com` in `src/main.jsx` with your email address.
2. Replace the placeholder LinkedIn (`https://www.linkedin.com/`) and GitHub (`https://github.com/`) URLs with your actual profile URLs.
3. Verify all project descriptions and employment details.
4. To offer a resume download, put `resume.pdf` in a new `public` folder and add a link to `/resume.pdf`.

## Deploy for free

Push this folder to GitHub, import the repository at Vercel, select Vite (or let it auto-detect), and deploy. Vercel's free Hobby tier is suitable for a personal noncommercial portfolio subject to its terms. You can connect a custom domain later.
